# Machine Learning Lab Experiments (FML)

This repository contains Jupyter Notebook implementations for 10 Fundamentals of Machine Learning (FML) lab experiments:

- **Experiment 1:** Create CSV Files & Load into Internal Data Structures
- **Experiment 2:** Python Programming for Loading the Data (`csv` & `pandas`)
- **Experiment 3:** Data Cleaning (Duplicates, Missing Values, Types)
- **Experiment 4:** Data Visualization (Bar, Line, Pie, Hist, Boxplot, Heatmap)
- **Experiment 5:** Scikit-learn Linear Regression (Hours vs Marks)
- **Experiment 6:** Non-Parametric Locally Weighted Regression (LWR with Gaussian Kernel)
- **Experiment 7:** Simple Linear Regression (Single Feature on Diabetes Dataset)
- **Experiment 8:** Multiple Linear Regression (Diagnostics, VIF, Joblib)
- **Experiment 9:** Housing Price Prediction (Linear, Ridge, RandomForest with GridSearchCV)
- **Experiment 10:** FIND-S Concept Learning Algorithm on PlayTennis

A combined master notebook containing all 10 experiments is available as `fml_lab_manual.ipynb`.
